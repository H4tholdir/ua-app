System prompt cacheato (Anthropic)
Il prompt di sistema (~8.000 token) descrive l'intera PWA: tutti i flow, le regole MDR, la struttura del DB, i 24 tool, le regole di sicurezza. Viene cacheato da Anthropic (5 min TTL) → 90% risparmio sui token di sistema.
RLS garantisce isolamento dati
L'IA usa il JWT dell'utente autenticato per tutte le query. Row Level Security di Supabase si applica automaticamente: l'IA di Filippo non può mai vedere dati di altri laboratori, anche se lo chiede.
