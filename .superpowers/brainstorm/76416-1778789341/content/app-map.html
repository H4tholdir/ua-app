⚡ Flow Operativi Principali
1. Nuovo Lavoro
~30-90 secondi
Tap "+ Nuovo" → Cerca dentista → Paziente (voce ok) →
Tipo dispositivo (6 tile) → Data consegna → Note →
CREA → ritorno dashboard
2. TAP CONSEGNA ★
1–3 secondi — operazione CORE
Lavoro 'pronto' → Screen consegna →
1 tap → precheck 8 campi MDR →
genera DdC + Buono + Fattura (parallelo) →
upload Storage → PEC + link WhatsApp →
animazione successo + confetti
3. Tracking Produzione
~20-30 secondi per fase
Dashboard → lista lavori assegnati →
Dettaglio → Tab Fasi →
Esegui fase → Salva → % aggiornata →
100% → stato 'pronto' automatico
4. Portale Dentista
link senza login
Lab genera link token → condivide WhatsApp/email →
Dentista apre link (no login) →
Vede lavori aperti → scarica DdC →
lascia feedback PMCF
5. Onboarding Nuovo Lab
wizard 6 step
Francesco crea lab /admin → invito email →
Titolare clicca link → Wizard: dati lab + logo +
PRRC nomina + PEC SMTP + primo cliente + listino
